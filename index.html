How I work

  • Start from the number that matters (sales, sign-ups, enrollments), not the deliverable.
  • Plain words beat precise-sounding ones.
  • Say what the data can’t support, not just what it can.
  • Change one thing, measure it, then change the next.
  • Write it so it survives being skimmed.
  • Hand over something the client can run without me.
